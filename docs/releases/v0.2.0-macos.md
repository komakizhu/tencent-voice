# TencentVoiceMVP 0.2.0

macOS 正式版，包含已确认的图标与状态栏视觉方案。

## 本版内容

- 使用 Apple 风格圆角矩形的主 App 图标，避免白色正方形画布直接露出。
- 状态栏图标使用透明模板资源，由 macOS 按浅色/深色状态栏自动渲染。
- 状态栏图标与主图标保持同一语音气泡和竖条语言，并完成最终比例调整。
- 权限准备由脚本打开对应的系统设置页面，应用日常启动不重复主动申请权限。
- Rime 皮肤定稿版本为 `0.2.0-V2`。

## 验证

- Swift 测试：193 项通过。
- macOS App 签名校验通过。
- 本地正式构建版本：`0.2.0 (build 44)`。

安装包由 GitHub Actions 在 macOS runner 上构建并作为 Release 附件发布。
