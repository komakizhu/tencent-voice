# Rime 皮肤版本

当前版本：`theme-1.0.0`

这是独立于 App build 的皮肤配置版本号，用来记录颜色和布局方案的迭代。当前版本是已经确认满意的定稿基线。

配置文件：`rime/squirrel.custom.yaml`

## 版本规则

- `patch`：只调整颜色、明暗或细节间距。
- `minor`：新增、删除皮肤，或增加一种明暗模式。
- `major`：改变皮肤配置结构或候选栏行为。

## 1.0.0

- 保留 Blue Reverie、Paper、Sage、Solarized、Nord、Dracula 及对应模式。
- 四个通用深色皮肤采用更深的近黑背景，同时保留原定高亮色。
- Sage Dark 使用更深的背景，并保留明亮的绿色高亮。
